# مسار ٤ — التجربة (UX / Frontend)

مواصفات تجربة Furn-App: الشاشات الثلاث، التنقّل، طبقة العرض، والتفاعل الذي يُصيّر
حلقة الثقة. البريف الكامل في `docs/workstreams/4_experience.md`، والحدود بين المسارات
في `docs/agent_workstreams.md`.

| الوثيقة | المحتوى |
|---|---|
| [`00-audit.md`](00-audit.md) | تدقيق التجارب الثلاث كما هي اليوم — ١٧ فجوة مُسنَدة إلى الشيفرة، وما هو سليم ولا يُلمس |
| [`01-experience-map.md`](01-experience-map.md) | المعمار المعلوماتي، هرمية الشاشات والأوراق، خمسة تدفّقات، جرد التفاعلات، والترتيب التنفيذي المقترح |
| [`02-copy-and-states.md`](02-copy-and-states.md) | صوت المنتج، المعجم المُلزِم، وحالات كل شاشة بنصّها الدقيق |
| [`03-design-system-contract.md`](03-design-system-contract.md) | عقد استهلاك نظام التصميم مع مسار ١ — الملكية، الـtokens، ومسار تدفّق القيمة |

**الحالة:** التسليمات الأربع الأولى (تدقيق + تصميم) مكتملة. **بانتظار موافقة المؤسّس
قبل أيّ كود** — لا سطر واحد نُفِّذ من المقترحات.
