## ٢) قواعد النصّ الصلبة

1. **نظام أرقام واحد.** كل الأرقام الظاهرة — المكتوبة يدويًّا والمُولَّدة — **لاتينية**
   (`3,000 ريال`)، لأن كل قيمة حيّة تخرج كذلك من `formatSar`. تُصحَّح النصوص المكتوبة
   بالهندي-العربي: `assistant_screen.dart:71` · `assistant_sheet.dart:36` ·
   `plan_screen.dart:447`. *(البديل — تحويل كل شيء إلى هندي-عربي — يتطلّب تدخّلًا في
   `formatters.dart` وهو مشترك؛ يُقترح على المعماري إن فُضّل.)*
2. **العملة** تُكتب «ريال» بعد الرقم دائمًا، عبر `formatSar` حصرًا. لا «ر.س» ولا «SAR».
3. **الثقة** نسبة مئوية صحيحة بلا كسور: `72%`.
4. **المقاسات**: الغرفة بالمتر (`4 × 3.7 م`)، القطعة بالسنتيمتر
   (`110 × 60 × 45 سم`)، بمسافة حول `×`.
5. **لا علامات تعجّب.** الإيموجي في موضع واحد فقط: لحظة الوصول (👏).
6. **كل نصّ ظاهر يقبل الالتفاف** — لا نصّ يُفترض أنه سطر واحد إلا داخل شارة.

### ٥.٥ غرفتي `/room` ★

العنوان العلوي: **غرفتي** `[يُعدَّل]` — اليوم «خطتي»، والمعجم يحجز «غرفتي» للتجربة.

| الحالة | النصّ |
|---|---|
| تحميل | **`[يُعدَّل]`** دوّارة عارية اليوم ⇐ **جاري بناء خطتك…** |
| خطأ | **`[يُعدَّل]`** اليوم `'تعذّر تحميل الكتالوج: $e'` ⇐ **تعذّر تحميل قائمة الأثاث. تحقّق من اتصالك وأعد المحاولة.** + **إعادة المحاولة** |
| **خطة فارغة** | **`[جديد]`** (ح-١٣): **لا قطع في خطتك بعد.** · **ارفع سقف ميزانيتك أو اطلب قطعة من المساعد لتبدأ.** — ويُستبدل الزرّ المعطّل بهذا النصّ |
| جاهز | الحالة الطبيعية `[موجود]` |
| منتهٍ | خطتك جاهزة. أنت جاهز 👏 + عدد القطع والإجمالي `[موجود]` |

**نصوص البطاقات** (`[موجود]` ما لم يُذكر):

| الكتلة | النصّ |
|---|---|
| الثقة | ثقتك في الخطة · `72%` · ≥80: «خطة متكاملة — أنت قريب من القرار.» · <80: «كل ما تعدّله يقرّبك أكثر من خطة تطمئن لها.» *(العتبة من المحرّك — ح-٧)* |
| لترفع ثقتك | «لترفع ثقتك» + `+النقاط` + label + الأفعال — **كلها من المحرّك، لا نصّ من عندنا** |
| الضمانات | مكتملة · ضمن الميزانية · تناسب الغرفة · متوفّرة |
| ما تغيّر | «أضفنا …» · «أزلنا …» · «زادت التكلفة …» · «وفّرت …» |
| الميزانية | الميزانية · إجمالي الخطة الآن: … |
| الناقص | ينقص خطتك: + شرائح إضافة |
| الفجوات المعلنة | طلبتها ولا نوفّرها · تقديرات سوق — ليست أسعارنا · خارج نطاقنا حاليًا. · ضمن نطاقنا، غير متوفّرة عندنا بعد. · لا يوجد خيار يناسب غرفتك وميزانيتك. |
| القطع | قطع خطتك · ثبّت/مثبّتة · بدّل · أزل |
| الشريط السفلي | هذه هي خطتي — أنا مطمئن · (منتهٍ) تعديل · شارك |
| بطاقة الـAR | **معلّقة على قرار ح-٥** |

> **قرار مطلوب على ح-٥ (بطاقة الـAR):** ثلاثة خيارات — (أ) تُحذف من «غرفتي»
> وتُنقل إلى المعاينة حيث موضوعها الطبيعي؛ (ب) تُربط بقطعةٍ من خطة المستخدم فعلًا بدل
> طاولة ثابتة؛ (ج) تبقى. أرشّح **(أ)**: «شاهدها في غرفتك» فعل رؤية، ومكانه المعاينة —
> وهذا يفرغ القلب لحلقة الثقة وحدها. زرّ `ArButton` على القطعة التي تملك نموذجًا يبقى
> كما هو (`plan_screen.dart:534`) لأنه مرتبط بقطعة حقيقية.

## ٦) أين يعيش النصّ — الهيكلة المقترحة

**المشكلة (ح-٩):** ٢٤ ثابتًا ميّتًا في `app_strings.dart` مقابل ١٨٧ نصًّا مكتوبًا
داخل الشاشات. لا سطح واحد للنصّ، ومسار الترحيل إلى ARB مقطوع.

**المقترح — خطوتان، بلا إعادة كتابة:**

1. **حذف الثوابت الميّتة الأربعة والعشرين** (شاشات محذوفة: مُنتقي الطريقة، الصوت،
   الصورة، التوصيات، حفظ المشروع). حذفٌ صرف بلا أثر سلوكي.
2. **إعادة التنظيم حسب التجربة**، فيصير موضع النصّ مقروءًا من اسمه:

```dart
class AppStrings {
  static const common = _Common();     // الأفعال والأخطاء المشتركة
  static const door = _Door();         // /
  static const assistant = _Assistant();// /assistant + /manual + /thinking
  static const room = _Room();         // /room + أوراقها
  static const preview = _Preview();   // /preview
}
```
النصّ المُوَلَّد (سطر «ما تغيّر»، رسائل الأوامر) يبقى حيث يُبنى — فهو تركيبٌ لا ثابت.

**الترحيل تدريجي:** كل مرحلة من §٧ في الخريطة تنقل نصّ الشاشة التي تمسّها فقط. لا
commit واحد ينقل ١٨٧ نصًّا — ذلك إعادة كتابة، وهي ممنوعة.

**الحدود:** `AppStrings` في `lib/core/constants/` — ليس ضمن ما يملكه مسار ٤ صراحةً في
جدول §٢ من الميثاق. أطلب من المعماري إمّا إسناده لمسار ٤ (فهو نصّ واجهة صرف) وإمّا
مراجعة الحذف. **لا ألمسه قبل الحسم.**

## ٧) ما يجب أن يثبته الاختبار

كل حالة أعلاه تُترجَم إلى اختبار widget واحد. الحدّ الأدنى المقترح لتغطية القلب (ح-١٦):

| الاختبار | يثبت |
|---|---|
| `plan_screen_test` — التصيير | الثقة والضمانات والقطع تظهر على خطة مُبذَرة |
| `plan_screen_test` — الحلقة | بعد «أزل»: الثقة تتغيّر **وسطر «ما تغيّر» يظهر** |
| `plan_screen_test` — الفراغ | خطة بلا قطع تعرض نصّها لا زرًّا معطّلًا |
| `plan_screen_test` — الخطأ | فشل الكتالوج يعرض رسالة بشرية + إعادة محاولة، بلا نصّ استثناء |
| `analysis_screen_test` — `idle` | حالة «لم يبدأ تحليل» لا دوّارة أبدية |
| `sandbox_screen_test` | المشهد يعرض قطع الخطة نفسها (بعد ح-١) |
| `saved_projects_test` | الفراغ يعرض فعلًا يخرج منه |
| `assistant_sheet_test` | أمر مفهوم يعرض سطر نتيجة؛ ومجهول يعرض التوجيه |
| `a11y_test` | حلقة الثقة تحمل وصفًا دلاليًّا يذكر الموضوع لا الرقم وحده |
