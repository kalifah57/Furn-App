# توزيع شغل النوّاب الثلاثة على الشاتات
## كل مهمة نائب → منفّذ واحد مسمّى (شات، أو المؤسّس، أو المعماري) — لا مهمة بين الكراسي

> القاعدة: النائب «قبّعة»، والشاتات أيدي القبّعة. ما لا يصلح لشات (ورق حكومي،
> توقيع عقود) يُسمّى منفّذه البشري صراحةً + من يجهّز له المسودات.
> التقارير الأسبوعية للشاتات تصل المعماري، وهو يعيد تجميعها للمؤسّس **بعدسة
> النوّاب**: سطر لكل نائب — رقمه تحرّك أم لا.

---

## النائب الأول — المنتج والهندسة (رقمه: نسبة من يعتمد خطة يثق بها)

| الشغلة (بالبسيط) | المنفّذ | وين هي الآن |
|---|---|---|
| قواعد الذوق (ألوان/خامات/تناسق) ورفعها ٨٣٪→٩٠٪ | **شات التصميم** | شغّال — برنامج شهره أ١–أ٣ |
| فهم كلام العميل + «ممنوع تسأله عن شيء قاله» | **شات الفهم** | شغّال — U5 وبرنامج شهره |
| الشاشات والأزرار والإصلاحات الستة + الأسئلة داخل المحادثة | **شات الشاشات** | شغّال — X9/X8 (X8 منجزة قيد الدمج) |
| جودة الجوال (كل تعديل يُجرَّب على بناء ويب حقيقي) | **شات الشاشات** + المعماري يعيد الفحص | قاعدة دائمة |
| حراسة الجودة والدمج والنشر وفض النزاعات | **المعماري** | مستمر |
| الصدق المبرمج (محجوزات، فئة فارغة، رسائل بلا تخمين) | المحرّك عند **المعماري** + عرضه عند **الشاشات** | شغّال |

**فجوات؟ لا شيء** — شغل النائب الأول مغطًّى بالكامل بأربعة منفّذين.

## النائب الثاني — الإمداد والشراكات (رقمه: متاجر موقَّعة + قطع حقيقية حيّة)

| الشغلة | المنفّذ | وين هي الآن |
|---|---|---|
| قائمة الأثاث الحقيقية (الدفعة الأكمل: أسرّة/سجاد/إضاءة + صور) | **شات الكتالوج** | نايم بأمر المؤسّس — يصحى لحظة قراره، وكل شيء يشتغل لحاله |
| مخطّط حقول الذوق التي تُعبّأ في القائمة | **شات التصميم** يسلّمه (D2) → الكتالوج يملؤه | ضمن برنامج شهر التصميم أ١ |
| **اتفاقية محل التجربة** (سرّية/ملكية بيانات/حصرية) | **المؤسّس يوقّع** — و**المعماري يجهّز مسودة النقاط** التي يبني عليها المحامي (A9) | جديد — أُسند الآن |
| اختيار المحل الأول والتفاوض معه | **المؤسّس** (علاقة بشرية لا شات) | بيدك — بعد جاهزية المسودة |
| عقود العمولة مع المتاجر | **المؤسّس** + المعماري يجهّز صيغة العرض التقني (رابط تتبّع، تقرير عمولة) | بعد نجاح التجربة |
| مجسّمات 3D للقطع | **فرع الكتالوج (3D)** | مؤجَّل عمدًا — خارج أساسيات التجربة |

**فجوتان مسمّاتان عمدًا:** العقود والتفاوض «شغل بشر» — الشاتات تجهّز الورق وأنت تمضي.

## النائب الثالث — الطلب والتشغيل (رقمه: ريال متوقَّع لكل زيارة + أوراق سليمة)

| الشغلة | المنفّذ | وين هي الآن |
|---|---|---|
| لوحة الأرقام («في إقبال أو لا؟») | **شات النموّ** | برنامج شهره أ٢ — بانتظار إصلاح زر الموافقة عند الشاشات |
| حسبة العمولة المتوقَّعة لكل خطة | **شات النموّ** | برنامج شهره أ٣ |
| خصوصية الناس (لا جمع بلا إذن + لا معلومات شخصية) | **شات النموّ** (النصوص والبوابة) + **شات الشاشات** (زر الموافقة يظهر ويشتغل) | شغّال عند الاثنين |
| تقرير «وش ما فهمناه» يغذّي شات الفهم | **شات النموّ** → شات الفهم | جاهز (G5) |
| **تسجيل المؤسسة + العلامة التجارية** | **المؤسّس** (خطوات حكومية) — والمعماري يجهّز checklist الخطوات والأوراق | جديد — يُجهَّز مع مسودة الاتفاقية |
| صوت العميل (ملاحظات تجربة المحل → مهام) | **المؤسّس يلتقط** → **المعماري يوزّع** على الشاتات | هذا حرفيًّا نظام الـdogfood الشغّال اليوم |
| التسويق وجلب المستخدمين | مؤجَّل عمدًا حتى تنجح تجربة المحل | — |

## خلاصة التوزيع بسطر لكل شات
- **شات التصميم** → يخدم النائب الأول (وقطعة واحدة للثاني: مخطّط D2).
- **شات الفهم** → النائب الأول بالكامل.
- **شات الشاشات** → النائب الأول (وقطعة للثالث: زر الموافقة).
- **شات النموّ** → النائب الثالث بالكامل تقريبًا.
- **شات الكتالوج** → النائب الثاني (نائم بانتظار قرار المؤسّس).
- **المعماري** → عمود النائب الأول + مُجهِّز أوراق الثاني والثالث + مجمِّع
  التقارير بعدسة النوّاب.
- **المؤسّس** → ثلاث مهام لا يفعلها غيره: توقيع اتفاقية المحل، تسجيل
  المؤسسة/العلامة، والتقاط ملاحظات التجربة.
