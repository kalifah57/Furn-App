## ١) جملة المؤسّس — المِحكّ المقدّس

> «غرفة نوم ٤×٣٫٥، أبي سرير معدني أسود ١٢٠×٢٠٠ ومرتبة، كومدينو خشب جوز، علاقة ملابس،
> سجادة بيج وستائر تعتيم، وأبي ثلاجة صغيرة — ميزانيتي ٣٠٠٠»

| الحقل | قبل (mock @ HEAD) | بعد (هذه الدورة) |
|---|---|---|
| نوع الغرفة | ✅ bedroom | ✅ bedroom |
| الأبعاد | ✗ ‎4×3‎ (بُترت العشرية) | ✅ ‎4×3.5‎ |
| الميزانية | ✗ ‎0‎ (لا كلمة عملة) | ✅ ‎3000‎ |
| القطع الأساسية | ✗ {سرير، سجادة} | ✅ {سرير، سجادة، تخزين} |
| الألوان | ✗ — (لا استخراج) | ✅ {أسود، جوز، بيج} → `style.colors` |
| خارج النطاق | ✗ — (يُسقَط بصمت) | ✅ {مرتبة، ستائر، ثلاجة} → `warnings` |
| ضمان «لا توصية» | ✅ | ✅ |

**النتيجة المقيسة: ‎١/٦ → ٦/٦‎.**

> ملاحظة صدق: التقرير التمهيدي قدّر «قبل» بـ٢/٦؛ **القياس الفعلي ١/٦** (العشرية
> المبتورة تجعل الأبعاد خطأً لا صوابًا). الرقم الأصدق أقلّ، فأثبتناه.

الحادثة الأصلية («أعطى كل شيء فسُئل عن الميزانية والألوان») كانت **عيب استخراج**
بحتًا لا عيب حارس: المحرّك يسأل عن حقلٍ فارغ فقط؛ لمّا امتلأت الحقول اختفت الأسئلة.
يثبت ذلك اختبار العقد `test/ai/no_question_for_provided_field_test.dart`.

## ٢) الفجوات — قبل/بعد (كلٌّ صار حالة corpus **قبل** إصلاحه)

| الفجوة | العَرَض | الإصلاح في الاستخراج | حالة الـcorpus (اختبار أوّلًا) |

| **G-01** الميزانية بلا كلمة عملة | يُسأل عمّا أجاب | ٣ طبقات: عملة → كلمة «ميزانية/بحدود…»+رقم → «N ألف»؛ مضاعِف ألف/آلاف | E-19، E-20، E-21 |
| **G-02** لا ألوان/خامات | الثيم يضيع + يُسأل عمّا أجاب | ١٢ لونًا قانونيًّا → `style.colors`؛ الخامات → `warnings` (R-2) | E-24، E-28، E-16 |
| **G-03** الفاصلة العشرية العربية `٫` تُبتَر | غرفة أصغر ١٤٪ بصمت | تطبيع `٫`→`.` و`٬` يُحذف؛ الأبعاد تقبل `.` و`,` | E-17، E-18 |
| **G-04** مفردات القطع ناقصة | قطع تختفي | توسيع: كومدينو/علاقة ملابس/تسريح…→storage، نجف/ثريا/أباجور…→lamp، تخت→bed | E-24، E-25، E-26 |

## ٣) إعادة إنتاج أرقام المحاكي (الأوراكل ↔ ما ستؤكّده CI)

| السطح | العدد | الحكم |
|---|---|---|
| أوامر `strict` (القديمة الخضراء) | **١٦/١٦** | ✅ لا انحدار |
| أوامر `baseline` (فجوات المُحلِّل، مُحرَسة بأرضية) | **٢٢/٤٩ = ٤٥٪** ≥ ‎0.40‎ | ✅ |
| استخراج `strict` (شامل جملة المؤسّس E-16) | **٢٨/٢٨** | ✅ |
| مِفصل G-14 (استخراج→محرّك) | المؤسّس ‎0‎ أسئلة · حارس-دقيق يسأل الميزانية فقط · العبث يسأل الأبعاد+الميزانية | ✅ |

> أوامر `baseline` تُوثّق فجوات **مُحلِّل مسار ٤** (مفردات/إملاء/آلاف بالكلمات/إنجليزية)
> بصدق كفجواتٍ مُحرَسة لا كأخطاء مخفيّة؛ لم أُصلحها لأنها خارج ملكيّتي هذه الدورة.
> إصلاح الاستخراج المقابل داخل ملكيّتي **مُطبَّق ومُختبَر strict** (مثال: E-20 «٣ آلاف
> ريال» → 3000 يمرّ، بينما نظيره الأمريّ C-42 يبقى baseline).

عدم الانحدار مضمون بنيويًّا: الحالات الخضراء القديمة (E-01..E-03، الأوامر ١٦) لم
تتغيّر توكيداتها، ومنفذ الأوراكل يعيد إنتاجها ١٦/١٦ و٣/٣.

## ٤) الحدود الجوهرية (لم تُكسَر)

- **افهم لا تُقرّر:** `recommendations` تبقى فارغة دائمًا (توكيد في كل حالة استخراج).
- **المجهول يُعلَن لا يُخمَّن:** بلا أبعاد/ميزانية → المحرّك يعلنها ناقصة (E-08/E-09).
- **لا سؤال عن حقلٍ مُعطى:** عقد `no_question_for_provided_field_test.dart` (٤ اختبارات).
- **لا خسارة صامتة:** ما لا يُلتقَط بنيويًّا (خارج نطاق/خامة/مقاس قطعة) يصل عبر `warnings`.
- **القياس قبل/بعد:** هذا التقرير، بأرقامٍ مقيسة لا مُتذكَّرة.
