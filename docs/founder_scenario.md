# سيناريو المؤسّس — شقّة حقيقية، بوابة قبول للتطبيق كله
## «إن لم يخطّط التطبيق شقّتي أنا، فلن يخطّط شقّة أحد»

> شقّة المؤسّس الفعلية: جدران بيضاء، أرضية كريمي، نافذة سوداء. الثيم المعتمد:
> **خشب جوز 🟤 + قماش بيج/رمادي فاتح + أسود مطفي ⬛ + أبيض**. هذا هو سيناريو
> الـdogfood القانوني: كل دفعة كتالوج وكل معايرة تناغم وكل تدفّق تجربة تُقاس عليه.

## جملة الإدخال (الشات — نصًّا كما يكتبها مستخدم حقيقي)
```
غرفة نوم ٤×٣٫٥، أبي سرير معدني أسود ١٢٠×٢٠٠ ومرتبة، كومدينو خشب جوز،
علاقة ملابس، سجادة بيج وستائر تعتيم، وأبي ثلاجة صغيرة — ميزانيتي ٣٠٠٠
```
(الصالة مشروع ثانٍ — التطبيق يخطّط غرفةً لكل مشروع؛ تعدّد الغرف في جلسة واحدة
ميزة مستقبلية مسجّلة لا مبنية.)

## معايير القبول (تُفحص مع كل دفعة/إصدار)
1. **الفهم:** الجملة أعلاه تستخرج: نوم ٤×٣٫٥ · ميزانية ٣٠٠٠ · سرير/تخزين/سجادة
   أساسيات · مرتبة/ستائر/ثلاجة تصل قائمة النطاق.
2. **غرفتي:** خطة ضمن الميزانية **الفعّالة** (بعد حجز الثلاجة والمرتبة والستائر)،
   والمحجوزات معلنة بشرائحها، والثقة صادقة بفجواتها القابلة للتنفيذ.
3. **التناغم (بعد D7):** طقم أسود+جوز+بيج يسجّل تناغمًا عاليًا؛ إقحام قطعة
   حمراء لامعة يخفضه بفجوة مشروحة.
4. **المعاينة:** سرير ١٢٠×٢٠٠ يدخل غرفة ٤×٣٫٥ بممرّ سليم، والتكبير يعمل.
5. **الروابط:** كل قطعة تفتح صفحة `/sa/en/` حقيقية (نيّة الشراء تُقاس).

## متطلبات دفعة الكتالوج المشتقّة (مُلزِمة للدفعة الجديدة)
- سرير **معدني أسود ١٢٠×٢٠٠** واحد على الأقل (GRIMSBU/SAGSTUA أو مكافئ) + أسرّة أخرى.
- كومدينو/تخزين بلون خشبي دافئ + ستاند علاقة أسود.
- كنب مقعدين بيج/أوف-وايت + طاولتا تلفزيون وقهوة بخشب جوز/بني دافئ **متطابقتَي النغمة**.
- سجاد بيج بمقاسات غرفة وصالة + فئة إضاءة ممثّلة (فجوة الدفعة الأولى).
- صورة لكل منتج، وروابط `/sa/en/`، وأرضيات الفئات محترمة.
