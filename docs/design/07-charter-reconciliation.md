## ٢) «تناغم الغرفة» يُطابق `ConfidenceGap` الحقيقي حرفيًّا

البريف §٤: «اقتدِ به حرفيًّا». وثيقة `02` حاكت `UnmetNeed` لأن `ConfidenceGap` لم يكن
موجودًا وقتها. الآن الشكل الحقيقي معروف، فأُطابقه:

```
// الموجود (المعماري) — plan/plan.dart:
class ConfidenceGap { final String label; final int points; final List<String> actions; }
class ReplacementOption { final CatalogProduct product; final List<String> pros, cons; }
```

**`HarmonyGap` يصير صدى مباشرًا له:**

| حقل `ConfidenceGap` | حقل `HarmonyGap` المقابل |
|---|---|
| `label` | `label` — «وحّد حرارة الباليت» |
| `points` (0..100 يكسبها بالسدّ) | `points` — نقاط التناغم المستردّة |
| `actions` (خطوات نصّية) | `actions` — «بدّل الكنب برمادي دافئ» |
| — | `ruleId` (إضافتي الوحيدة: `'C2'` — تتبّع للمواصفة، وشرحٌ بجملة) |

والإصلاح الملموس **يعيد استخدام `ReplacementOption` كما هو** (لا نوع جديد): البديل
بمقاسه وسعره مع `pros`/`cons`. المثال المؤسِّس يصير:

```
HarmonyGap(
  label: 'وحّد حرارة الباليت',
  points: 15,                                  // 79 → 94، محسوبة لا مُدّعاة
  actions: ['بدّل الكنب برمادي دافئ ليوافق دفء الجوز'],
  ruleId: 'C2',
)  +  ReplacementOption(product: كنب_greige, pros: ['يوافق حرارة الغرفة'], cons: [])
```

> النتيجة: تناغم الغرفة يتكلّم **نفس لغة الثقة** التي يعرفها المستخدم والمعماري ومسار ٤ —
> `points` + `actions`، لا مفردات موازية. وثيقة `02` حُدّثت لتعكس هذا.

**موضع `HarmonyReport`:** يُحسب في `lib/domain_engine/design/` (نطاقي، Dart صرف، يستهلك
`Plan`/`Room`/`CatalogProduct` قراءةً). ربطه **داخل** `Plan` (كما `confidenceGaps`) تغييرُ
عقدٍ مشترك ⇒ **spec + PR للمعماري**؛ وإلّا يبقى مخرجًا مستقلًّا يستهلكه مسار ٤.

| القاعدة | مصدر المعايرة | الاختبار | مثال ذهبي | الحالة |

| سمات الستايل (5) | Bonn Furniture Styles (موسومة) | اتّفاق٪ مع التسميات | modern ≠ classic | ⏳ ينتظر ابتلاع البيانات |

| إضاءة/تشبّع `L*`/`C*` | CIELAB | شرائح 0..4 | ✅ منفَّذ (دفعة ١) | ✅ أخضر |
| تنافر C2 (حرارة) | CIE ΔE2000 + قطب b* | `temperaturesClash` | brown×gray_cool ⇒ تعارض | ✅ أخضر (البذرة) |
| C1/C3–C6 (باليت) | Itten + ISCC families | خصومات على مجموعة | 60/30/10 | ⏳ مع دفعة التناغم |
