## ١) موقعها في حلقة التدريب والاختبار

المجموعة الذهبية هي **الحقيقة الأرضية** التي تُعايَر عليها القواعد. مصدر حكمها **قاعدة
تصميم معتمدة** (لغة التصميم `01` + مصادر `06`)، لا ذوق. الحلقة:

```
D1 المجموعة الذهبية  →  D3 قواعد التناغم  →  D4 المنصّة تقيس الدقّة  →
D5 تحليل الأخطاء ← تعديل قاعدة ← إعادة قياس  →  حتى ≥٩٠٪ (الإتقان)
```

> الحالة ليست «هل تبدو حلوة؟» — بل «هل يحكم عليها المصدرُ المعتمد بكذا، وهل قاعدتي توافقه؟».

## ٢) بنية الحالة الواحدة

| الحقل | النوع | الغرض |
|---|---|---|
| `id` | نص | `col-temp-01` — مُصنّف بالمحور |
| `category` | `color·style·material·scale·cross·majlis` | محور الاختبار الأساسي |
| `rule` | نص | القاعدة الحاسمة: `C2`, `styleAffinity`, `M1`, `S3`… — **تتبّع للمواصفة** |
| `room` | `{type, width_m, length_m, height_m?}` | سياق الغرفة (المقياس يُقاس ضدّها) |
| `pieces[]` | قائمة قطع | كلٌّ: `category, style[], colors[], materials[], wood_tone?, width_cm, depth_cm, height_cm, subcategory` |
| `expected.verdict` | `harmonious·dissonant` | الحكم المتوقّع |
| `expected.band?` | `high·medium·low` | شريحة التناغم المتوقّعة (اختياري) |
| `reason_ar` | **جملة واحدة** | لماذا — بلغة يفهمها المستخدم |
| `authority` | نص | القاعدة/المرجع المعتمد الذي يُصدر الحكم |

**المفردات** (نفس لغة التصميم، فالمنصّة تشغّلها مباشرة):
- ستايلات: `modern · minimal · classic · industrial · boho · majlis`
- ألوان (رموز `01 §2.3`): `white · off_white · gray_warm · gray_cool · beige · black · brown · blue · gold · red`
- خامات: `wood · fabric · metal · leather · glass · ceramic`؛ `wood_tone: light · medium · dark`

### صيغة الـ fixture المقترحة (JSON — تقرأها منصّة D4)

```json
{
  "id": "col-temp-01", "category": "color", "rule": "C2",
  "room": {"type": "living_room", "width_m": 4, "length_m": 5},
  "pieces": [
    {"category":"sofa","style":["modern"],"colors":["gray_cool"],"materials":["fabric"],
     "width_cm":210,"depth_cm":90,"height_cm":85,"subcategory":"sofa"},
    {"category":"table","style":["modern"],"colors":["brown"],"materials":["wood"],
     "wood_tone":"medium","width_cm":110,"depth_cm":60,"height_cm":45,"subcategory":"coffee_table"},
    {"category":"rug","style":["modern"],"colors":["beige"],"materials":["cotton"],
     "width_cm":200,"depth_cm":290,"height_cm":1,"subcategory":"area_rug"}
  ],
  "expected": {"verdict": "dissonant", "band": "medium"},
  "reason_ar": "الجوز الدافئ والرمادي البارد يتجاذبان في اتجاهين فتفقد الغرفة تماسك حرارتها.",
  "authority": "تناغم الحرارة اللونية (قطبا CIELAB b*) — قاعدة C2"
}
```

> JSON لا Dart: بيانات صرفة يقرؤها الـ harness (D4)، ويسهل على غير المبرمج مراجعتها وتوسيعها.
> `test/domain_engine/design/golden/v1/*.json` + فهرس.

## ٥) القياس وعتبة الإتقان

- **الدقّة** = نسبة الحالات التي يوافق فيها حكمُ قاعدتي حكمَ المرجع (على `verdict`، ثم على
  `band` كطبقة أدقّ).
- **الإتقان:** ≥٩٠٪ على v1 (D5) **دون كسر قابلية الشرح** — كل قاعدة تبقى جملة واحدة.
- الإخفاقات تُصنَّف بـ`rule` فتُوجّه المعايرة (D4 يُخرج قائمة مصنّفة).
- **مضادّ للغش:** لا نضبط عتبة على النتيجة، ولا نكتب قاعدةً تحفظ حالةً بعينها — القاعدة عامّة
  وتُشرح، وإلا رُفضت.

## ٦) ما أطلبه الآن

راجِع: (أ) **بنية الحالة** (§٢) — هل المدخلات/الحكم/السبب كافية؟ (ب) **الـ١٥ عيّنة** (§٤) —
هل الأحكام والأسباب سليمة على العُرف المعتمد، وهل تمثيل المجلس كافٍ؟

عند موافقتك أُكمل الستّين وأكتبها fixtures في `test/domain_engine/design/golden/v1/`، ثم أنتقل
إلى D3/D4. **موقوف بانتظار المراجعة — لا كود fixtures قبلها.**
