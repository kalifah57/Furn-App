# المجموعة الذهبية v1 — fixtures التناغم

٦٠ حالة محكومة (غرفة + قطع → متناغمة/متنافرة + سبب بجملة + القاعدة المرجعية). **الحقيقة
الأرضية** لبرنامج التدريب والاختبار (backlog D1). البنية والمنهج: `docs/design/08-golden-set-v1.md`.

## الصيغة
- بيانات JSON صرفة (لا كود). **ليست `_test.dart`** فلا يشغّلها `flutter test` — منصّة D4
  ستقرؤها عبر `dart:io` وتشغّلها على قواعد التناغم.
- ملف لكل محور + `index.json` (فهرس بالعدّ والتوزيع). حقول الحالة في الوثيقة `08 §2`.

## المحتوى (index.json)
- **٦٠ حالة:** لون ١٦ · ستايل ١٢ · خامة ١٠ · مقياس ٩ · عبر-محاور ٩ · مجلس ٤.
- **مجلس-سياق: ١٤** (~٢٣٪) — جلسة أرضية، باليت دافئ، ضيافة لا عرض.
- الأحكام: ٣٤ متناغمة · ٢٦ متنافرة (متوازنة، لا انحياز لفئة).

## اتّساقها (تحقّق ساكن قبل الكتابة)
- **٤٥ حالة قابلة للتحقّق آليًّا** من قواعدها (حرارة/ستايل/إشغال/نغمات خشب…): **صفر تعارض** —
  الحكم المؤلَّف يطابق ما تحسبه القاعدة.
- **١٥ حالة سلطةٌ تصميمية** (C6 تباين الإضاءة · M3 الخشونة×الستايل · S1 القطعة الخفيفة ·
  X1/X2 التشبّع/الكتلة×الستايل · C3 كثرة العائلات): حكمها من المرجع المعتمد، وبعضها **يتجاوز
  قواعد v0 عمدًا** — فيظهر إخفاقًا في baseline (D4) ويصير هدف معايرة (D5). هذا مقصود: مجموعةٌ
  تطابقها القواعدُ كلَّها ١٠٠٪ لا تُدرّب شيئًا.

## مضادّ الغشّ
لا قاعدة تُكتب لتحفظ حالةً بعينها، ولا عتبة تُضبط على النتيجة. كل قاعدة عامّة وتُشرح بجملة
عربية واحدة، وإلا رُفضت — مهما رفعت الدقّة.
